## 📂 Repository Structure

### ☕ 1. [Java Algorithms & Data Structures](java-algorithms/)
Practical implementations from Semester 1 **Algoritma & Pemrograman (Alpro)**:
- **Arrays & Matrices**: 1D/2D arrays (`Init1Dim.java`, `Larik1Dim.java`, `JumlahKolomdanBaris.java`, `MatriksXY.java`).
- **Looping & Iterations**: `dowhile.java`, `perulangan.java`, `While.java`, `While2.java`.
- **Conditional Logic & Arithmetic**: Discount & taxation calculations (`Diskon.java`, `Pajak.java`, `Riil.java`), character identification (`Identifikasihuruf.java`), mathematical quadratics (`kuadrat.java`).
- **Mini-Projects**: Admission system simulation (`PenerimaanSiswaBaruSMA1Ponorogo.java`) and Academic Information System structure (`SISTEMAKADEMIK.java`).

### 🐍 2. [Discrete Mathematics in Python](discrete-math-python/)
Scripts from Semester 1 **Matematika Informatika (MatFor)**:
- **Set Theory (Himpunan)**: Set union, intersection, difference, and Venn representations (`union.py`, `intersection.py`, `venn3.py`).
- **Propositional Logic**: Boolean logic, implication, and truth tables (`implication.py`, `Index.py`).
- **Matrix Mathematics**: Matrix operations, additions, and linear transformations (`Matriks.py`, `Matriks2.py`, `Matriks2a+b.py`, `Matriks3.py`, `MATRIKS4.py`).
- **Algorithms**: Array sorting, manipulation, and search operations (`Sort.py`, `Reverse.py`, `Pop.py`, `Remove.py`).

### 🐘 3. [Object-Oriented Programming in PHP](oop-php/)
Exercises from Semester 2 **Pemrograman Berorientasi Objek (PBO)**:
- Class definitions, object instantiation, encapsulation, and inheritance (`Hewan.php`, `buah.php`, `buku.php`, `Hp.php`, `pegawai.php`, `perpustakaan.php`).
